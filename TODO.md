# Создание библиотеки для фреймворка Joke по генерации аватаров 

Назначение модуля генерировать изображение-аватар по заданному никнейму. На вход должен принимать никнейм (обязательный параметр) и тему (если не передана или передана не известная - применять тему по умолчанию). Картинка должна из себя представлять квадрат. Размер задается в настройках модуля. Формат картнки PNG. Фон выбирается случайным образом из диапазона заданного в теме, над фоном можно случайнм образом расположить маленькие квадраты, отличающимся (но не контрастным цветом). Количество так же случайное. И над этим всем первые два символа никнейма цветом заданным в теме.

Примечание по реализации
- Использовать PHP 8.5
- Использовать расширение GD для генерации изображений
- использовать фреймворк https://github.com/Voral/joke

Архитектура
- Сервис AvatarGenerator (бизнес-логика).
- AvatarProvider (наследник Vasoft\Joke\Provider\AbstractProvider) для регистрации сервиса в DI-контейнере.
- AvatarConfig (наследник Vasoft\Joke\Config\AbstractConfig) для хранения настроек (размер, темы).
- Конфигурация тем: Определи структуру конфигурации для 'Темы'. Тема должна включать: массив возможных цветов фона, цвет текста, диапазон цветов для декоративных квадратов. Приведи пример дефолтной темы в конфиге
- Обработка ошибок: все ошибки генерации должны оборачиваться в кастомное исключение `AvatarException` унаследованное от JokeException
- Код должен быть строго типизирован (strict_types=1).
- должно быть кеширование автаров в подкаталоге <корень_проекта>/var/cache/avatars/

Примечания по стилю кода
- Код писать как сеньор, глубоко владеющий приниципамми построения архиеткутры и хорошего стиля кода. 
- Применять PER-CS3. 
- PhpDoc на русском языке для всех public/protected методов.
- Следовать принципам SOLID, особенно SRP (сервис только генерирует, не отдает HTTP-ответ напрямую, если это не контроллер).
- Учитывать стилистику применяемую в фреймворке Joke
